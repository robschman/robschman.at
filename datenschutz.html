Datenschutzerklärung

Der Schutz personenbezogener Daten wird ernst genommen. Diese Erklärung beschreibt, welche Daten beim Besuch dieser Website anfallen und was damit geschieht. Sie ist bewusst kurz — denn diese Website erhebt so wenig wie möglich. Die vollständige Anschrift des Verantwortlichen ist am Ende dieses Dokuments aufgeführt.

Das Wichtigste vorweg

  • Keine Cookies. Diese Website setzt keine Cookies. Deshalb gibt es auch kein Cookie-Fenster.
  • Kein Tracking, keine Werbung. Es ist kein Werbenetzwerk eingebunden und es werden keine Nutzerprofile gebildet. Die Besucherzahlen werden cookielos gezählt — siehe „Besucherstatistik“ weiter unten.
  • Keine Formulare. Es gibt kein Kontaktformular und keine Newsletter-Anmeldung. Es werden bewusst keine Adressen gesammelt.
  • Schriften vom eigenen Server. Die Schriften liegen auf dem Server dieser Website, es wird nichts von Google Fonts oder ähnlichen Diensten nachgeladen. Einzige Datei von einem anderen Anbieter ist das kleine Zählskript, das im Abschnitt „Besucherstatistik“ beschrieben ist.
  • Keine Weitergabe. Es werden keine Daten verkauft oder zu Werbezwecken weitergegeben.
